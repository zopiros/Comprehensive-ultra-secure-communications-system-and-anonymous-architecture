# - لینک اصلی این سایت : https://zopiros.github.io/-/
این پروژه یک وب‌اپلیکیشن تک‌صفحه‌ای (SPA) تعاملی، سبک و خوداتکا است که جهت تحلیل، بررسی و انتخاب بهترین راه‌کارهای ارتباطی فوق‌امن، پروتکل‌های ضد شناسایی (Anti-DPI)، رمزنگاری پساکوانتومی (PQC) و امنیت عملیاتی (OPSEC) بر اساس اسناد نظامی و ریپازیتوری‌های معتبر سال ۲۰۲۶ طراحی شده است.

🚀 ویژگی‌های کلیدی پروژه

🎯 ارزیاب هوشمند مدل تهدید: محاسبه خودکار بهترین پشته امنیتی (پیام‌رسان، سیستم‌عامل، شبکه و رمزنگاری) متناسب با سطح تهدید، هدف ارتباطی و سخت‌افزار در دسترس.

📊 تجسم داده‌های پویا (Chart.js):

نمودار زمان‌بندی کوچ به PQC (الزامات NSA CNSA 2.0 در برابر اتحادیه اروپا).

نمودار راداری ۵ بعدی برای مقایسه پیام‌رسان‌های P2P (SimpleX، TFC، Signal Molly).

نمودار مقایسه‌ای قدرت استتار در برابر سرعت برای پروتکل‌های ضد DPI.

🔌 بررسی تخصصی دیود سخت‌افزاری نوری TFC: تشریح معماری Tinfoil Chat برای جداسازی فیزیکی دستگاه‌های آنلاین و آفلاین.

⚡ پوشش کامل جدیدترین پروتکل‌های ضد فیلترینگ (۲۰۲۶): بررسی Xray VLESS-REALITY، XHTTP، AmneziaWG 3.1، MASQUE (HTTP/3) و پنهان‌نگاری ویدیویی Stegozoa.

📋 چک‌لیست ۶ مرحله‌ای OPSEC: دستورالعمل عملیاتی گریز از شناسایی و تحلیل فراداده.

📐 معماری و ساختار بخش‌ها

برنامه از ۷ تب اصلی و کاملاً ایزوله تشکیل شده است:

🎯 ارزیاب تهدید (Threat Evaluator): ماتریس تصمیم‌گیری هوشمند مبتنی بر JavaScript برای انتخاب ابزار متناسب.

🏛️ دکترین نظامی و PQC: بررسی استانداردهای NSA CSfC، DARPA، ANSSI و BSI همراه با نقشه راه جایگزینی RSA/ECC با ML-KEM و ML-DSA.

👤 ارتباط P2P (کاربر به کاربر): کالبدشکافی پیام‌رسان‌های بدون شناسه، سیستم TFC و شبکه Reticulum.

🌐 ارتباط با سایت‌ها (Clearnet & Darknet): استانداردهای OHTTP، μODoH، ECH، SecureDrop ۲۰۲۶ و معماری Tor Arti با Rust.

🌪️ میکس‌نت‌ها (Mixnets): تحلیل شبکه‌های Katzenpost، Nym و روش‌های اثبات دانش صفر (PIR) برای شکست ناظر جهانی غیرفعال (GPA).

⚡ ضد فیلترینگ (Anti-DPI): تحلیل فنی کانال‌های پنهان، uTLS fingerprinting و استتار ترافیک UDP/TCP.

💻 سیستم‌عامل و OPSEC: راهنمای پیکربندی Qubes OS، Tails، GrapheneOS و چک‌لیست امنیتی ۶ مرحله‌ای.

🛠️ تکنولوژی‌های استفاده‌شده

این پروژه با رعایت اصل سادگی، امنیت و عدم وابستگی به سرویس‌دهنده‌های خارجی در زمان اجرا ساخته شده است:

HTML5 & Vanilla JavaScript (ES6+): مدیریت وضعیت برنامه و موتور تصمیم‌گیری ارزیاب تهدید.

Tailwind CSS (CDN): طراحی رابط کاربری تاریک (Dark Mode)، واکنش‌گرا و مدرن در کلاس Cyber Slate.

Chart.js (v4): رندر نمودارها در محیط Canvas بدون استفاده از فایل‌های گرافیکی SVG یا Mermaid.

Vazirmatn Font: فونت استاندارد و بهینه‌سازی‌شده برای زبان فارسی و چیدمان راست‌به‌چپ (RTL).

💻 راهنمای اجرای برنامه

برای اجرای این برنامه نیازی به نصب هیچ‌گونه ابزار توسعه، Node.js، یا سرور محلی (Web Server) ندارید.

فایل index.html را دریافت کنید.

آن را مستقیماً در مرورگر دلخواه خود (Chrome, Firefox, Brave, Tor Browser) باز کنید (Double Click یا Drag & Drop).

تمام قابلیت‌های تعاملی، تغییر تب‌ها، نمودارها و ابزار ارزیاب تهدید بلافاصله قابل استفاده خواهند بود.

🔒 نکات امنیتی و حریم خصوصی

فاقد تلمتری (No Telemetry): هیچ‌گونه داده‌ای از مرورگر یا ورودی‌های کاربر جمع‌آوری، ذخیره یا به سروری ارسال نمی‌شود.

اجرای محلی کامل: تمام محاسبات و فرآیندهای تعاملی به صورت کلاینت-ساید (Client-side) درون مرورگر انجام می‌گیرد.

طراحی شده برای محیط‌های ایزوله: پروژه قابل اجرا در سیستم‌عامل‌های آفلاین یا محیط‌های Whonix/Tails است.
